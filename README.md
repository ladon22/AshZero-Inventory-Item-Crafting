# AshZero - Inventory / Item / Crafting / Store System

Unreal Engine 5.5.4, C++ 로 개발한 팀 프로젝트 AshZero 중, 제가 담당한 인벤토리·아이템·장비·제작·상점 시스템 코드를 발췌한 저장소입니다.

- 팀 프로젝트: 개발 3명, 기획 5명, 아트 6명 (총 14명)
- 원본 버전 관리: SVN (팀 정책상 GitHub 미사용) — 이 저장소는 포트폴리오 공개용으로 새로 구성한 것입니다.
- 담당 범위: 인벤토리, 아이템, 장비, 제작, 상점 시스템 / 멀티플레이 동기화(Server RPC) / 기획자용 커스텀 에디터 툴

## 주의 사항

- 이 저장소는 팀 프로젝트에서 **제가 작성한 파일만 발췌**한 것입니다. 다른 팀원이 작성한 캐릭터, 카메라, 퀘스트, 맵 생성 등의 코드는 포함되어 있지 않습니다.
- 다른 시스템과의 의존성 때문에 이 저장소 자체만으로는 **빌드되지 않습니다.** 코드 구조와 구현 방식을 보여주기 위한 발췌본입니다.
- `PlayerController_발췌/` 폴더는 팀 공용 파일인 `AZPlayerController`에서 제가 작성한 함수(인벤토리 이동, 상점, 제작 관련 Server RPC)만 따로 뽑아둔 것입니다.

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| `Inventory/` | 가변 크기·모양의 그리드 인벤토리 (`AZInventoryComponent` 및 파생 컴포넌트) |
| `Item/` | 아이템 베이스 클래스, 가방 아이템, 상자/루팅 |
| `Crafting/` | 제작 컴포넌트, 레시피 데이터 테이블 |
| `Store/` | 상점 서브시스템, 구매/판매 UI |
| `DataPipeline/` | DataTable 기반 아이템 데이터 관리, GameInstanceSubsystem 캐싱 |
| `EditorTool/` | 기획자가 코드 수정 없이 가방 그리드 모양을 설정할 수 있는 커스텀 디테일 패널 |
| `UI/Inventory/` | 인벤토리 관련 UMG 위젯 |
| `PlayerController_발췌/` | 공용 PlayerController 중 담당 RPC 함수만 발췌 |

## 핵심 구현 포인트

- **가변 그리드 인벤토리**: 가방마다 크기와 모양(L자형 등 불규칙 형태 포함)이 다르도록 `FBagDefinition`으로 설계
- **커스텀 에디터 툴**: `IPropertyTypeCustomization` 기반으로 디테일 패널에 체크박스 그리드 UI를 그려 기획자가 직접 가방 모양을 편집
- **Data-Driven 설계**: 크래프팅 레시피, 상점 가격 등을 DataTable로 관리해 재컴파일 없이 콘텐츠 반영
- **멀티플레이 동기화**: 아이템 획득/이동/버리기 등 모든 인벤토리 조작을 Server RPC로 처리하고, 소유권 검증 로직으로 다른 플레이어의 컴포넌트를 대상으로 한 부정 조작을 서버 단에서 차단
